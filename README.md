# Proyecto-Desarrollo-de-la-IA
*Alumno: Rios Gonzalo Gabriel
*Carrera: Recuros Digitales.
*Tema: Herramientas Utilizadas en Diseño Front End y Back End en los ultimos 5 años, y los cambios que hubo en el desarrollo con la IA como soporte.

## Proceso para el desarrollo del trabajo investigativo 

### Perplexity

Utilicé Perplexity para realizar la recaudación de información sobre la evolución del Front End, Back End y el desarrollo de la Inteligencia Artificial como herramienta de soporte durante los últimos años. También me permitió consultar diferentes fuentes para obtener información relacionada con el tema.

### Google Drive

Utilicé Google Drive para guardar los dos archivos Excel y el documento Word utilizados posteriormente para el análisis y desarrollo del sitio web.

### Cuaderno Gemini

Utilicé Cuaderno Gemini para analizar los tres archivos recopilados: los dos Excel, correspondientes al Front End y Back End, y el documento Word sobre la evolución del desarrollo de software con IA. También lo utilicé para relacionar la información, identificar tendencias y organizar el contenido que posteriormente tendría el sitio web.

### Claude

Utilicé Claude para generar el sitio web HTML a partir de la información y el análisis realizados previamente en Cuaderno Gemini. Claude organizó el contenido en diferentes secciones e incorporó la navegación, gráficos, línea temporal, conclusiones y fuentes.

### Netlify

Utilicé Netlify para publicar el sitio web en Internet, tomando el archivo HTML generado y corregido previamente para convertirlo en una página web accesible mediante un enlace.
